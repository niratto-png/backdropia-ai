# Backdropia AI - Game Assets Generator

AI-powered game backgrounds and UI assets generation SaaS.

## Features

- 🎨 **AI Image Generation** - Generate studio-quality game backgrounds in 30 seconds
- 🎮 **Multiple Styles** - Fantasy, Cyberpunk, Sci-Fi, Pixel Art, Anime, Realistic
- 💳 **Stripe Integration** - Easy subscription management
- 📦 **High Resolution** - Up to 1920x1080 output
- 🚀 **Fast Processing** - Powered by Stable Diffusion API

## Pricing

- **Starter** - $4.99/month (30 generations, 5 styles)
- **Pro** - $14.99/month (200 generations, 20 styles)
- **Studio** - $49.99/month (Unlimited, API access)

## Tech Stack

- **Frontend**: Next.js 14 + React 18 + TypeScript
- **Backend**: Node.js + Express
- **Database**: Supabase (PostgreSQL)
- **Payment**: Stripe
- **AI**: Stable Diffusion API (Replicate)
- **Hosting**: Vercel

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/niratto-png/backdropia-ai.git
cd backdropia-ai
npm install
```
